# Бот-органайзер «Седьмой квант»

## Описание проекта
Бот-помощник для учебных чатов, который решает проблему потери домашних заданий, дедлайнов и анонсов олимпиад. Пользователь пересылает сообщение или скриншот в бота, а тот распознает текст, находит дату, время и тип задачи, сохраняет всё в базу данных и вовремя напоминает.

## Целевая аудитория
Школьники 5–11 классов, родители и учителя.

## Основной функционал
- Прием текстовых сообщений и картинок (распознавание текста через Tesseract OCR).
- Автоматическое определение типа задачи (ДЗ, олимпиада, встреча, дедлайн).
- Извлечение даты и времени из текста (поддержка форматов «15.11», «завтра», «через 3 дня», «в пятницу в 14:30»).
- Сохранение задач в локальную базу данных SQLite.
- Отправка напоминаний в назначенное время.
- Удобное меню с кнопками для просмотра профиля и списка задач.
